<hijri-calendar>

A dependency-free Web Component. Drop in one <script>, add the tag, point it at an input.

1. Popup date picker bound to an input

<input id="dob" type="text">
<input id="dob-hijri" type="text" readonly>

<hijri-calendar
  target="#dob"
  target-hijri="#dob-hijri"
  popup
  format="iso"
  hijri-format="hijri"
  miqaats-url="miqaats.json">
</hijri-calendar>

2. Inline calendar with miqaat badges, custom output format, Monday weeks

Wide enough, each miqaat shows as a pill with its icon and a truncated title. Narrow grids and popups fall back to compact icon markers.

<hijri-calendar
  target="#appt"
  format="hD hMMM hYYYYH [=] D MMM YYYY"
  week-start="monday"
  numerals="latin"
  max-badges="2"
  miqaats-url="miqaats.json">
</hijri-calendar>

<style>

3. Zero-markup: auto-create from the script tag

<input id="auto" type="text">
<script src="hijri-calendar.js"
        data-target="#auto"
        data-popup
        data-format="hijri"></script>
